# Студия взгляда Елены Павленко — мини-сервис подбора услуг

Мобильный интерактивный мини-сайт: клиент за 1–2 минуты проходит персональный
подбор наращивания ресниц и оформления бровей, видит предварительную стоимость
и формирует карточку заявки для мастера (копируется в буфер обмена).

## Структура

```
index.html      — разметка, подключение стилей и скрипта
style.css       — премиальный мятно-золотой дизайн, анимации, 3D-сцена
app.js          — логика подбора, балльная система объёма (1D–3D), расчёт, карточка мастера
assets/
  favicon.svg   — фавикон (глаз)
README.md
```

## Логика подбора ресниц

Каждый ответ начисляет баллы объёмам 1D / 1.5D / 2D / 3D. Лидер становится
рекомендацией; если два лидера отличаются максимум на 1 балл — клиенту
предлагается выбор «натуральнее / выразительнее».

## Прайс (все цены в app.js → PRICES)

- 1D — 2100 ₽ · 1.5D — 2200 ₽ · 2D — 2300 ₽ · 3D — 2400 ₽
- Растушёвка — 200 ₽ · Снятие своей — 200 ₽ · Снятие чужой — 300 ₽
- Коррекция бровей — 300 ₽ · Архитектура бровей — 900 ₽
- Удаление волосков на лице (1 зона) — 300 ₽
- Комплекс «ресницы + брови» — 600 ₽ (информационно, не суммируется автоматически)

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите файлы (корень репозитория = корень сайта).
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Бэкенд не требуется — всё работает на чистом JavaScript.
